# Portal 2

*Status: 🔨 In Planning*

A second multi-tenant application designed to explore microservices architecture and advanced patterns.

## Planned Features

### Architecture
- Microservices-based design
- API Gateway pattern
- Event-driven communication
- Service mesh (future)

### Technical Goals
- Horizontal scaling with Kubernetes
- Message queues (RabbitMQ/Redis)
- Distributed tracing
- Circuit breakers

### Learning Objectives
- Practice Kubernetes orchestration
- Implement event sourcing
- Explore CQRS pattern
- Master service discovery

## Tech Stack (Planned)

- **Backend:** Node.js microservices
- **Frontend:** React
- **Database:** PostgreSQL (per service)
- **Message Queue:** RabbitMQ
- **Orchestration:** Kubernetes
- **Monitoring:** Prometheus + Grafana
